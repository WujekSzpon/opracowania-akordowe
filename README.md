# Opracowania Akordowe od Wujka Szpona

Interaktywny konspekt opracowań akordowych. Dane są pobierane z pliku KONSPEKT - AKORDY.xlsx, a okładki znajdują się w katalogu okladki.

Strona: https://wujekszpon.github.io/opracowania-akordowe/

## Najczęściej aktualizowane pliki

- KONSPEKT - AKORDY.xlsx - baza utworów i linków,
- okladki/ - okładki przypisane do pozycji w arkuszu,
- index.html - kod konspektu.
